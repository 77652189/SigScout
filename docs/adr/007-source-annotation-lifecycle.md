# ADR-007：来源蛋白评估与候选刷新解耦

## 背景

候选获取和来源蛋白定位证据查询具有不同的网络成本与更新节奏。刷新时强制重评会增加失败面，也可能把已完成注释重置为未评估；完全依赖名称关键词又缺乏可靠性。

## 决策

候选刷新只负责获取和筛选信号肽；来源蛋白定位作为独立操作，使用 UniProt 受控位置、特征和 GO 细胞组分证据。刷新时按稳定 accession 保留已完成的 `source_protein_*` 字段，用户主动重评时才更新证据与查询时间。

## 后果

刷新后可立即复用已有注释，外部证据服务不可用也不阻断候选获取。缺少足够细胞组分证据的来源保持未知，不根据信号肽存在强制分类。

## 替代关系

无。
