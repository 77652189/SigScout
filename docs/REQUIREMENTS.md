# SigScout 需求

## 定位

SigScout 是用于分泌表达设计前期的信号肽候选发现、解释、整理和实验引导探索的工作台。它把蛋白层面的候选信息转化为可审查、可复现的实验讨论输入。

## 能力边界

系统应能：

- 从支持的远程来源或本地 CSV 获取候选，保留重复及其证据；
- 用可解释的规则、可选的本地预测复核和来源蛋白证据辅助筛选；
- 将候选刷新与来源蛋白定位辅助评估分开执行，并保留可追溯的外部证据与查询时间；
- 聚类相似信号肽，保留完整候选并输出代表序列；
- 生成融合构建、导入外部定位结果，并导出 CSV、FASTA 与 JSON 摘要；
- 导入湿实验测量结果，以目标为边界生成包含正向邻域、通用支持、多样性和低表现对照的下一轮探索面板；
- 通过 CLI 和 Streamlit 提供同一工作流的入口。

系统不应：

- 声称预测真实分泌产量、跨批次可比性或统计显著性；
- 将短信号肽与完整 leader 在实验引导评分中混合比较；
- 将某一目标的实验反馈传播到其他目标，或仅凭相似序列宣称候选已经验证；
- 将实验反馈并入外部定位工具评分，形成不可解释的单一总分；
- 自动调用外部网页定位工具，或自动下载、提交受限模型资源；
- 承担 DNA/CDS 优化或其他项目的机理模型仿真职责。

## 验收标准

功能变更以相关测试、CLI 入口和受影响的 Streamlit 工作流验证为准。实验引导结果必须显示选择渠道和理由，并明确其是候选压缩工具而非产量预测器。

## 信息披露边界

公开 README 与受跟踪工程文档不得出现具体目标蛋白名称、其 accession 或点名该目标的文献引用。运行输出、外部工具目录和受限资源不纳入版本控制。
