# SigScout 执行计划

## 当前状态

目标隔离修复切片已完成实现：融合构建采用 schema v2 身份，构建清单可跨页面重启恢复，定位导入与缓存按目标和序列摘要校验，Streamlit 业务状态按目标隔离。旧定位缓存已废弃；用户需要重新生成 FASTA 并重新计算外部定位结果。

## 已完成能力摘要

- 已形成共享候选库、来源蛋白辅助评估、代表序列浏览和融合定位工作流。
- 已实现目标隔离的实验反馈、融合构建、定位缓存、交互状态与导出；无实验数据的目标不会继承其他目标证据。
- 已实现 `target + candidate + type + sequence SHA-1` 的融合构建身份、目标专属构建清单和严格定位导入门禁。
- 共享候选服务默认使用宿主信号肽库元数据；历史运行路径保留兼容名称，但旧目标标签不会传播到新构建。
- 已实现精确序列实验关联和分渠道的下一轮探索面板，实验结果不改变通用候选分或外部定位分。
- 已将 Streamlit 页面拆分为集中导航的视图模块，并保持 CLI 与 UI 经服务层进入业务流程。

## 明确不做

- 不把实验引导面板升级为生产产量预测模型；原因是当前数据与验证范围不支持该声明。
- 不因没有排队任务而进行无目标重构；原因是会扩大风险且没有验收目标。

## 重新评估触发条件

重大探针结束、资源预算变化、出现新的科学门禁、连续两个切片没有增加原始产品能力，或准备进入新阶段时，必须重新评估继续、并行、降级、换路线或停止，并取得相应授权。
